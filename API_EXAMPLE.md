# Rugged API example

```bash
curl https://YOUR-RENDER-SERVICE.onrender.com/v1/chat/completions \
  -H "Authorization: Bearer rk_std_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "rugged-ai",
    "messages": [
      {"role":"user","content":"Hello from my app"}
    ],
    "stream": false
  }'
```

The `rk_...` key is generated by your Rugged AI API, not by OpenAI.

## Developer keys (no account)

Open `frontend/developers.html` (or the deployed Developer Portal) and generate a General or Adult-capable API key. The full secret is returned only once. Store it securely.

Use it with the OpenAI-compatible endpoint:

```bash
curl "$RUGGED_API_URL/v1/chat/completions" \
  -H "Authorization: Bearer rk_std_..." \
  -H "Content-Type: application/json" \
  -d '{"model":"rugged-local","messages":[{"role":"user","content":"Hello"}]}'
```

A portal key can be revoked once by calling `POST /developer/keys/revoke` with that key as the Bearer credential.
