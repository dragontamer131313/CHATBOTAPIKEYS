# Rugged AI Platform v6

Local-first, browser-capable chatbot platform.

- WebGPU/WebLLM local inference
- Conservative device capability detection
- Cached local model/runtime
- Offline-capable PWA shell
- Optional Rugged API fallback
- Accounts and Rugged API keys
- Health checks, request-size limits and configurable concurrency
- No OpenAI API key required for local inference

Read `SETUP.md` for deployment and developer API-key instructions.
